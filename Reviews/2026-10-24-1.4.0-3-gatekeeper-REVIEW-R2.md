## Findings (severity-ranked; all code facts re-verified first-hand at the seal)

### P2 (MEDIUM) — confirmed

1. **Claims-truth FALSE row (changelog).** `README.md:178` and `README.md:184`: "atomic per-value overlay writes" attributed to 1.4.0-2. Drone forensic evidence: `git log -S renameSync` → `dbbed2f`, tag-contained in `v1.4.0-1`. Third consecutive gate with an attribution-level changelog miss in exactly this pattern; the prior receipt's P3-12 + repair rider named the reword and it was not applied. Repair (owner's call, one hunk): attribute atomic rename to 1.4.0-1 in both sentences (e.g. "(the `Number.isSafeInteger` cap guard ships in 1.4.0-2; atomic per-value overlay writes shipped in 1.4.0-1)"). 
2. **`nonTaskCalls` steering expired as a safety property — eviction expires DISTRACT.** `src/subagent.js:215/:421` — eviction drops an id from the distrust set; then `resolveCallId` rule 2 *trusts* an explicit parent that was once a distrusted wait/bash call, `adoptUnseenCall` adopts a non-task call as a task call, and non-empty `adoptedCalls` permanently suppresses rule 3 for the whole session. Blast radius: long sessions (>4000 non-task starts) with recurred late misattribution. One eviction → one mis-adoption → one unrecoverable session state. Local fix: eviction should bound memory only, never change resolution outcomes — either evict a bounded replacement (oldest-first that resolution still treats as distrusted) or make adoption records re-verifiable (reconciliation can demote an adopted id it later observes as non-task).
3. **Provenance window escapes: ownerless stragglers and post-sweep adoptions run to completion.** `src/subagent.js:549-550 + 651-656` — requires `ownerCallId ≠ null` AND owner ∈ `preAbortCalls`; (a) stragglers with no attribution run invisible (pre-1.4.0-3 window covered exactly this case); (b) a call adopted *after* the sweep can never be in the frozen snapshot even if it started pre-abort — "known at abort" ≠ "started before abort" on a knowledge-bounded timeline. (b) is undisclosed in comment/README/comment; (a) is half-disclosed ("left to reconciliation"). Architect: LOCAL — snapshot ownerless tracked children at sweep; let reconciliation feed pre-abort call ids into the window.
4. **Disarm-guard seam untested at the proxy layer.** `src/proxy.js:108-113` — the whole headline fix ("plain prompt disarms; `abort_and_prompt` stays armed [armed across its own new turn]") exists as a regex + comment and no test drives it at the pipeline level; dropping the negative guard keeps 165/165 green (verified by grep: `createProxyPipeline` tests never assert the window state; `disarmAbort` in test only mirrors bridge-level).
